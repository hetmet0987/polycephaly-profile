# Polycephaly Profile v2.2

Personal digital identity website for **Polycephaly**.

## Stack

- Next.js 15
- TypeScript
- React 19
- Framer Motion
- Lucide React
- Vercel

## v2.2

Adds the final showcase: **APRIS — Advanced Photorealistic Rendering & Illumination System**.

APRIS is presented as an in-development rendering system:

- Current milestone: **0.07 Water Engine**
- Roadmap: **0.08 Weather → 0.09 Atmosphere/Volumetrics → 0.10 TAA/Denoising → 1.00 Photorealism**
- The showcase separates implemented functionality from roadmap targets.

## Run locally

From the project root:

```powershell
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Production build

```powershell
npm run build
npm start
```

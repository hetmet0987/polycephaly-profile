# APRIS Showcase Source Note

The Polycephaly showcase treats APRIS 0.07 as the current implementation milestone and 0.08–1.00 as roadmap targets.

Current: Foundation, PBR, Shadows, AO/Contact Shadows, Reflections, Global Illumination, and the 0.07 Water Engine.
Roadmap: 0.08 Weather, 0.09 Atmosphere/Volumetrics, 0.10 TAA/Denoising, 1.00 Photorealism.

The showcase intentionally does not present future roadmap items as implemented features.
